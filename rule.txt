코드 악보 만들기 규칙
=====================

지금까지 악보를 고치면서 정한 규칙을 정리한 것이다.
기준 파일: raw/145_*_AGD코드.html, raw/1256_*_GC코드.html, raw/1456_*_GC코드.html


1. 파일 이름
------------
- 형식: [코드번호]_[곡명]_[조]코드.html / .png
    예) 145_회상_AGD코드.html, 1256_10월의어느멋진날에_GC코드.png
- 맨 앞 숫자 = 곡에 쓰인 코드 번호(도수)
    145   → 1·4·5 코드만 쓰는 곡 (예: 회상, 연가, 등대지기, 여행을떠나요, 조개껍질묶어)
    1256  → 1·2·5·6 코드를 쓰는 곡 (예: 10월의어느멋진날에)
    1456  → 1·4·5·6 코드를 쓰는 곡 (예: 너의의미)
- 곡명은 띄어쓰기 없이 쓴다.
- 조 표시(맨 뒤):
    AGD코드 → 룰대로 만든 악보. A·G·D 세 조로 표기
    GC코드  → 룰대로 만든 악보. G·C 두 조로 표기
    그 밖의 [조]코드 → 원본 악보 (예: 145_회상_D코드_악보.png, 145_여행을떠나요_E코드.png)
- 원본 악보는 끝에 원본의 조와 "_악보"를 붙이기도 한다. (예: 1256_10월의어느멋진날에_G코드_악보.png)
- 마디정렬, 1·2절 같이 쓰기 같은 형식은 파일 이름에 넣지 않는다. (룰대로 만든 악보는 모두 같은 형식)
- 원본 파일은 고치지 않고, 바꾼 것은 새 이름으로 따로 저장한다.
  (비교용으로 저장할 때는 이름 끝에 _비교 같은 표시를 붙여 따로 저장)
- 작업 파일은 raw 폴더에 둔다.


2. 코드 줄 구성 (조 변환)
------------------------
- 145 곡 (1·4·5 코드만) → A·G·D 세 조의 코드로 변환해서 3줄로 쓴다.
    위   : A코드  빨강 #C00000   (A, D, E)
    가운데: G코드  파랑 #0057B8   (G, C, D)
    아래  : D코드  초록 #1E7B34   (D, G, A)
- 1256 / 1456 곡 → G·C 두 조의 코드로 변환해서 2줄로 쓴다.
    위   : G코드  빨강 #C00000
    아래  : C코드  파랑 #0057B8
- 원본이 어느 조든, 반음 단위로 옮겨서 위 조들로 맞춘다.
  (예: 원본 C코드 → G코드 +7, D코드 원본 → A코드로 옮긴 뒤 G·D로)
- 원본 악보가 여러 개면, 마디·코드 위치는 오선 악보(가장 정확한 악보)를 기준으로 한다.


3. 코드 표기
-----------
- 1·4·5 코드로만 이루어진 경우에 7코드가 있으면 그 7코드는 기본 코드로 수정한다.
    E7 → E,  D7 → D,  A7 → A,  G7 → G
- 코드가 바뀌지 않는 마디에도 같은 코드를 다시 적는다.


4. 코드 번호 (도수)
-----------------
- 맨 아래 코드 줄에만 번호를 붙인다.
    145 곡(AGD): D코드 줄 → D=1, G=4, A=5
    GC 곡      : C코드 줄 → C=1, Dm=2, Em=3, F=4, G=5, Am=6
- 번호는 코드 오른쪽에, 코드 글자와 같은 크기로, 진한 회색 #555 로 쓴다.
- 번호는 1(으뜸음)에서 떨어진 거리로만 매긴다.
  (조 밖의 코드도 번호를 붙임. 예: C조의 D=2, E=3, B=7)


5. 어려운 코드 표시
-----------------
- 곡의 기본 코드(1·2·5·6 또는 1·4·5)가 아닌 어려운 코드는 노란 형광펜 배경 #FFEB3B 로 표시한다.
  (예: 10월의 어느 멋진 날에 "득한"의 F#/B#, "걸~"의 B/E)
- 형광펜은 코드 글자에만 칠하고, 번호에는 칠하지 않는다.


6. 악보 형태 (마디정렬)
---------------------
- A4 한 장에 들어가게 만든다.
- 한 줄에 4마디, 모든 마디 폭을 같게 한다.
- 줄마다 가로선을 긋고, 코드는 가로선 위, 가사는 가로선 아래에 쓴다.
- 마디가 나뉘는 곳에 짧은 세로선(마디선), 곡 끝에는 겹세로줄(‖)을 넣는다.
- 박자표는 첫 마디 앞에, 가로선을 사이에 두고 숫자를 위아래로 쓴다. (예: 4/4, 6/8)
- 첫 가사가 못갖춘마디면, 첫 마디 칸에 코드 이름 안내(A코드/G코드/D코드)와
  그 가사(오른쪽 정렬)를 넣는다.
  첫 마디가 바로 코드로 시작하면, 코드 이름 안내는 제목 왼쪽 위에 둔다.
- 다음 마디로 이어지는 가사는 마디 오른쪽 끝에 붙인다.
  (예: "네 ······ 이미 그대 떠난")
- 마디 중간에서 코드가 바뀌면, 가사 길이에 맞춰 마디 칸을 나눈다.
- 앞 음을 끄는 곳은 "-" 또는 "~" 로 표시한다.
- 쉼표는 𝄽 로 표시한다.
- 1절/2절/후렴 같은 구역 표시는 넣지 않는다.
- Fine, D.C. 같은 반복 표시는 원본에 있으면 그대로 넣는다.


7. 여러 절 같이 쓰기
-------------------------------
- 여러 절의 코드 진행이 같으면 코드는 한 번만 쓰고,
  가사는 절 순서대로 위아래로 쓴다. (1절·2절 → 두 줄, 1·2·3절 → 세 줄)
  (예: 등대지기·10월의어느멋진날에 – 두 줄, 조개껍질묶어 – 세 줄)
- 두 절의 가사가 같은 부분은 한 줄로 쓴다. (예: 여행을떠나요 B 부분)
- 반복되는 끝부분은 없애고 바로 마지막 부분으로 이어지게 한다.
  (예: 10월의 어느 멋진 날에 – 반복되는 "더 좋은 것은 없을 거야"를 없애고
   2절 "야~" 다음에 "시월의 어느 멋진 날에"로 이어짐.
   "시월"은 "의 어느 멋진 날"과 같은 줄에 오게 위 줄에 둠)


8. 글자 크기와 모양
-----------------
- 형태(마디 수, 마디 폭, 줄 수)는 바꾸지 않고 글자만 키운다.
- 가사는 줄바꿈하지 않는다. 가사 폭은 가장 긴 마디에 맞춘 최대 크기로 한다.
- 가사를 더 크게 하려면 폭은 그대로 두고 세로로만 늘린다(최대 3배).
- 코드 크기는 줄이지 않는다.
  (코드와 가사를 비슷한 크기로 맞추는 방식도 있음: 코드 크기를 늘어난 가사 높이에 비례하게)
- 가사는 굵은 글씨(bold)로 쓰고, 진하게 하는 외곽선 효과는 쓰지 않는다.
- 가사끼리 붙어 보이면 폭에 여유를 조금 둔다.
- 글꼴: 맑은 고딕


9. 제목
------
- 제목 오른쪽에 가수/앨범 정보를 작은 글씨로 붙인다.
    회상 – 산울림8집(1982)
    등대지기 – 영국 민요 · 고은 작사
    연가 – 뉴질랜드 민요
    너의 의미 – 산울림, 아이유
    10월의 어느 멋진 날에 – 김동규


10. 가사
-------
- 원본 악보의 가사를 쓰되, 요청이 들어오면 고친다.


11. 출력 (PNG)
-------------
- HTML을 Edge 헤드리스로 A4(794x1123, 3배)로 캡처해서 PNG를 만든다. (2382 x 3369 픽셀, 약 288dpi)
- HTML을 고치면 PNG도 다시 만든다.


12. 기타코드표
------------
- 기타코드표_A4.png: A4 300dpi(2480 x 3508), 여백 10mm, 가운데 정렬.
- 기타코드표_A4_1단계.png: 1단계 기본 코드 8개
  A, Am, C, D, Dm, E, Em, G 의 칸 전체(이름+그림)를 노란 형광펜 #FFEB3B 로 표시.
- 형광펜은 곱하기 방식으로 칠해서 글자와 선이 그대로 검게 보이게 한다.
